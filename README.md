## 🧠 What is Byebye malware?

**ByeBye is an advanced Python-based Remote Access Trojan (RAT) that uses Discord as its Command & Control (C2) server. Once executed on a victim's computer, it connects to a Discord bot and waits for commands from the attacker.**

The malware is designed to:

Steal sensitive data (passwords, cookies, browsing history)

Spy on victims (webcam, microphone, screenshots, keylogging)

Control the system remotely (execute commands, upload/download files)

Maintain persistence (survives reboots)

Evade detection (bypasses antivirus, hides itself)

Encrypt files (ransomware-style capability)
.

## 🧠 How to use Byebye malware?

Configure the script - Replace DISCORD_TOKEN and CHANNEL_ID in the code with your Discord bot token and channel ID

Build the executable - Use PyInstaller to convert byebye.py to an EXE: pyinstaller --onefile --noconsole byebye.py

Deliver to victim - Send the EXE file via email, USB, fake download link, or social engineering

Victim runs it - Once executed, the malware hides itself and connects to your Discord channel

Get victim info - You'll receive system details, passwords, and location automatically in Discord

Send commands - Type commands like !cmd, !webcam, !passwords in your Discord channel

Exfiltrate data - All stolen data (files, screenshots, passwords) appears directly in your Discord
